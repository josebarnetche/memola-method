# Strategy Workshop Facilitation Guide
## MEMOLA Co-Creation Workshop Template

---

## Workshop Overview

This template provides a facilitation guide for MEMOLA strategy co-creation workshops, ensuring client participation as co-producers of strategic outcomes.

---

## WORKSHOP TYPES

| Workshop | Purpose | Duration | Phase |
|----------|---------|----------|-------|
| Discovery Workshop | Gather context, goals, constraints | 2 hours | Pre-Phase 1 |
| Findings Review | Present Phase 1-3 analysis | 3 hours | Pre-Phase 4 |
| Strategy Co-Creation | Develop strategic direction together | 4 hours | Phase 4 |
| Prioritization | Decide initiatives and resources | 2 hours | Phase 4 |
| Implementation Planning | Detail execution roadmap | 3 hours | Phase 4/5 |
| Quarterly Review | Assess progress, adjust plans | 2 hours | Ongoing |

---

# DISCOVERY WORKSHOP (2 Hours)

```

## Activity Guides

### Activity 1: Context Mapping (25 min)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│   CONTEXT MAPPING ACTIVITY                                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   PURPOSE: Understand business context and strategic priorities             │
│   TIME: 25 minutes                                                          │
│   MATERIALS: Whiteboard or digital canvas, sticky notes                     │
│                                                                             │
│   FACILITATION SCRIPT:                                                      │
│                                                                             │
│   "I'd like us to map your business context. We'll use four quadrants      │
│   to capture: what's working well, what's challenging, what you're         │
│   trying to achieve, and what constraints we should know about."           │
│                                                                             │
│   CANVAS:                                                                   │
│   ┌────────────────────────────┬────────────────────────────┐              │
│   │ WORKING WELL               │ CHALLENGES                 │              │
│   │                            │                            │              │
│   │ • [Participant inputs]     │ • [Participant inputs]     │              │
│   │ •                          │ •                          │              │
│   │ •                          │ •                          │              │
│   ├────────────────────────────┼────────────────────────────┤              │
│   │ GOALS                      │ CONSTRAINTS                │              │
│   │                            │                            │              │
│   │ • [Participant inputs]     │ • [Participant inputs]     │              │
│   │ •                          │ •                          │              │
│   │ •                          │ •                          │              │
│   └────────────────────────────┴────────────────────────────┘              │
│                                                                             │
│   PROCESS:                                                                  │
│   1. Explain the four quadrants (2 min)                                     │
│   2. Silent brainstorming - each person writes stickies (5 min)            │
│   3. Share and cluster - one quadrant at a time (15 min)                   │
│   4. Prioritize - star the most important in each quadrant (3 min)         │
│                                                                             │
│   PROBING QUESTIONS:                                                        │
│   • "What's driving that success/challenge?"                                │
│   • "How would you measure that goal?"                                      │
│   • "Is that constraint negotiable?"                                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

# FACILITATION BEST PRACTICES

## Ground Rules (Post Visibly)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         WORKSHOP GROUND RULES                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. ONE CONVERSATION - No side conversations                               │
│                                                                             │
│   2. ALL VOICES MATTER - Everyone contributes                               │
│                                                                             │
│   3. CHALLENGE IDEAS, NOT PEOPLE - Keep it constructive                     │
│                                                                             │
│   4. STAY PRESENT - Devices away except for emergencies                     │
│                                                                             │
│   5. PARKING LOT - Off-topic items captured for later                       │
│                                                                             │
│   6. DECISIONS STICK - We leave aligned                                     │
│                                                                             │
│   7. WHAT'S SAID HERE, STAYS HERE - Open dialogue is safe                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Facilitation Techniques Reference

```
TECHNIQUE               USE WHEN                      HOW
─────────────────────────────────────────────────────────────────────────────
Round Robin             Need all voices               "Let's go around..."
Dot Voting              Need quick prioritization     "3 dots each, place on top picks"
Silent Brainstorm       Avoid groupthink              "5 min writing, then share"
Think-Pair-Share        Complex topics                "Think alone, discuss with partner, share"
Five Whys               Getting to root cause         "Why?" repeated 5x
Parking Lot             Off-topic but valid           "Great point - parking lot"
Temperature Check       Gauge alignment               "Thumbs up/sideways/down"
Fist of Five            Measure agreement             "Show 1-5 fingers for agreement"
Timeboxing              Keep moving                   "You have 5 minutes"
Stand-Up                Energy boost                  "Let's stand for this one"
```

```
┌─────────────────────────────────────────────────────────────────────────────┐

│                                                                             │
