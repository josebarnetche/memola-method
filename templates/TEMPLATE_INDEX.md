## Customization Guidelines

### When to Customize

| Situation | Customization Approach |
|-----------|----------------------|
| Industry-specific client | Add industry terminology, relevant benchmarks |
| Shorter engagement | Combine phases, reduce slide count |
| Executive audience | Heavy executive summary, fewer details |
| Technical audience | Add methodology details, more data |
| Workshop participants | More interactive exercises, less presentation |

### How to Customize

1. **Start with the template** - Don't build from scratch
2. **Remove before adding** - Take out irrelevant sections first
3. **Maintain structure** - Keep the SCAR flow (Situation, Complication, Analysis, Recommendation)
4. **Preserve decision points** - Always include clear asks and next steps
5. **Test readability** - Ensure slides work in both presentation and document form

### Branding Notes

Templates are designed for easy branding:
- Replace "[CLIENT NAME]" with actual client name
- Add company logo to title slides
- Adjust color descriptions to match brand
- Maintain professional, clean design

## Presentation Best Practices

### Before Presenting

```
□ Review all data for accuracy
□ Practice key transitions
□ Prepare for likely questions
□ Test technology
□ Send pre-read if required
□ Confirm attendees and time
```

### During Presentation

```
□ Start with the headline, not the agenda
□ Tell the story of the data
□ Pause for reactions at key points
□ Use "we discovered" language (co-production)
□ Watch for body language and confusion
□ Stay on time
```

### After Presenting

```
□ Send summary within 24 hours
□ Include action items with owners
□ Attach relevant data/documents
□ Note outstanding questions
□ Schedule next meeting
□ Update internal tracking
```
