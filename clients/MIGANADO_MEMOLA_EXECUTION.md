## Reality 1: Adoption Friction in the Field

```
THE PRODUCER'S PERSPECTIVE

"Yo ya sé lo que tengo. ¿Para qué más papeles?"

├── Extra steps = rejection unless ROI is immediate and obvious
├── RFID exists, but data discipline is uneven
├── Any friction gets blamed on "la tecnología"
└── Consignatarios don't require any of this
```

**Strategic Implication:**

MiGanado must **integrate into existing workflows**, not replace them.

```
INTEGRATION PRINCIPLES

DO:
├── Pre-populate data from SENASA/existing sources
├── Mobile-first, offline-capable, minimal taps
├── Automate via hardware (RFID readers, scales) when possible
├── Make data entry a by-product of existing actions
└── Reward data quality with visible benefits (pricing, access)

DON'T:
├── Require separate "platform time" from producers
├── Ask for data that doesn't immediately benefit them
├── Build for desktop-first or connectivity-dependent
├── Create new administrative burden
└── Assume tech literacy beyond WhatsApp
```

**Product Requirement:**
Every data input must answer: "What does the producer get from entering this TODAY?"

├── Fraud = permanent platform ban
