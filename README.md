# MEMOLA Method

A comprehensive marketing consulting methodology based on servuction principles for marketing agencies helping business owners measure ROI, analyze competition, assess market share, and develop strategy.

---

## What is MEMOLA?

MEMOLA is a six-phase marketing consulting framework that treats clients as co-producers in the strategic process, based on the servuction model from Eiglier & Langeard (1989).

```
M - MEASURE      Audit marketing spend and establish ROI baselines
E - EVALUATE     Analyze competitive landscape and positioning
M - MAP          Size markets and calculate market share
O - OPTIMIZE     Develop data-driven strategic plans
L - LEVERAGE     Activate competitive advantages
A - ACCELERATE   Scale successful initiatives for growth
```

## The Six Phases

| Phase | Name | Focus | Key Deliverables |
|-------|------|-------|------------------|
| 1 | MEASURE | Marketing spend audit | Spend analysis, ROI baseline, waste identification |
| 2 | EVALUATE | Competitive analysis | Competitor profiles, share of voice, positioning map |
| 3 | MAP | Market sizing | TAM/SAM/SOM, market share, segment analysis |
| 4 | OPTIMIZE | Strategic planning | Marketing strategy, budget allocation, roadmap |
| 5 | LEVERAGE | Advantage activation | Competitive moats, differentiation execution |
| 6 | ACCELERATE | Growth scaling | Growth systems, expansion playbooks |

## Certification Levels

The MEMOLA Method is an acquirable skill with four certification levels:

### Level 1: Associate
- **Duration:** 6 weeks training
- **Scope:** Phases 1-2 (Measure & Evaluate)
- **Requirements:** 3 supervised engagements, 70/100 score
- **Role:** Execute audits and analysis under supervision

### Level 2: Practitioner
- **Duration:** 8 weeks training
- **Scope:** Phases 1-4 (through Optimize)
- **Requirements:** 5 engagements, 75/100 score, NPS 40+
- **Role:** Lead engagements independently

### Level 3: Strategist
- **Duration:** 10 weeks training
- **Scope:** All 6 phases
- **Requirements:** 7 engagements with ROI proof, 80/100 score
- **Role:** Lead complex engagements, supervise Associates

### Level 4: Master
- **Duration:** 12-24 months development
- **Scope:** Method advancement and leadership
- **Requirements:** Recognition-based (innovation, mentorship, thought leadership)
- **Role:** Innovate method, mentor practitioners, industry leadership

## Servuction Foundation

The MEMOLA Method is built on servuction principles, treating marketing consulting as a service production system:

```
┌─────────────────────────────────────────────────────────────────┐
│                    SERVUCTION SYSTEM                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   INVISIBLE                        VISIBLE                      │
│   (Back Office)                    (Front Office)               │
│                                                                 │
│   ┌─────────────┐                  ┌─────────────┐              │
│   │  Support    │                  │  Physical   │              │
│   │  System     │──────────────────│  Evidence   │              │
│   │             │                  │             │              │
│   │ • Data      │                  │ • Reports   │              │
│   │ • Tools     │                  │ • Dashboards│              │
│   │ • Research  │                  │ • Templates │              │
│   └─────────────┘                  └──────┬──────┘              │
│                                           │                     │
│                                    ┌──────┴──────┐              │
│                                    │  Contact    │              │
│                                    │  Personnel  │◄────────┐    │
│                                    │             │         │    │
│                                    │ • Analysts  │         │    │
│                                    │ • Strategist│    CO-PRODUCE│
│                                    └──────┬──────┘         │    │
│                                           │                │    │
│                                    ┌──────┴──────┐         │    │
│                                    │   CLIENT    │─────────┘    │
│                                    │             │              │
│                                    │ (Co-producer│              │
│                                    │  of service)│              │
│                                    └─────────────┘              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**Key Principle:** The client is not a passive recipient but an active co-producer of the marketing strategy. Their participation is essential to service quality.

## Getting Started

### For Training Directors

1. Review `MEMOLA_METHOD.md` for complete methodology
2. Review `training/TRAINING_PROGRAM_OVERVIEW.md` for certification structure
3. Select appropriate level training materials
4. Use assessment rubrics to evaluate candidates

### For Practitioners

1. Start with `training/LEVEL_1_ASSOCIATE_TRAINING.md`
2. Complete all modules and exercises
3. Conduct supervised engagements
4. Submit for certification assessment

### For Client Engagements

1. Use templates from `templates/` folder
2. Follow phase-appropriate presentation structure
3. Incorporate workshop facilitation guides
4. Establish monthly/quarterly review cadence

## Key Concepts

### Marketing Metrics
- **ROAS** - Return on Ad Spend
- **CAC** - Customer Acquisition Cost

- **SOV** - Share of Voice

### Market Sizing
- **TAM** - Total Addressable Market
- **SAM** - Serviceable Addressable Market
- **SOM** - Serviceable Obtainable Market

- First-touch, Last-touch, Linear, Time-decay, Position-based

| Level | Assessment Type | Components |
|-------|----------------|------------|

| Strategist | Portfolio + Case Study (100 pts) | Portfolio 40, Case Study 30, Leadership 20, Oral 10 |
